# LTI - Applicant Tracking System

Fullstack ATS project built as part of a Master's degree exercise.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | Kotlin + Spring Boot 3 |
| **Frontend** | React 18 + Vite 5 + TypeScript |
| **Database** | PostgreSQL 16 |
| **Infrastructure** | Docker + Docker Compose |

> 🚧 Project in progress — setup and documentation will be completed as development advances.
